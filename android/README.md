# Legacy Android-only runtime

The supported client is the **Kotlin Multiplatform** repository:

[bhargavcode/jetforge-kmp](https://github.com/bhargavcode/jetforge-kmp)

Use `JetForgeScreen` / `JetForgeComponent` from `:jetforge` (Android + iOS, shared Compose renderer — never a WebView). This folder is an earlier Android snapshot and is not the integration path for new apps.
